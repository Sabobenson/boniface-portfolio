Wireless Office Network + Security

Cisco Packet Tracer Academic Project

Overview

Design and simulation of a wireless office network with secure wireless connectivity and supporting network infrastructure, built to reflect how a small office would provide reliable and protected wireless access to its staff.

Design Approach

  • Planned wireless access point placement for coverage across the office space.
  • Configured DHCP to automatically assign addresses to wireless clients.
  • Applied baseline wireless security configuration to protect the network from unauthorized access.
  • Designed the IP addressing scheme to integrate cleanly with the wider office network.

Outcome

The result is a simulated wireless network that provides dependable connectivity to end devices while keeping access controlled and traffic organized, consistent with good practice for small-office wireless deployments.
