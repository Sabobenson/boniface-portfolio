Explainable AI Model for Pulmonary Edema Detection

Deep Learning Academic Project

Overview

An AI-based project for detecting pulmonary edema from chest X-ray images and providing explainable predictions using Explainable AI (XAI) techniques. The goal was not only to classify images accurately, but to make the model's reasoning visible and interpretable.

Approach

  • Built and trained a deep learning classifier on chest X-ray image data using TensorFlow/Keras.
  • Used a DenseNet121-based convolutional architecture for feature extraction and classification.
  • Applied Grad-CAM to generate visual explanations highlighting the image regions that most influenced each prediction.
  • Evaluated the model's classification performance alongside the interpretability of its explanations.

Why Explainability Matters

In a healthcare context, a prediction alone is not enough — clinicians need to understand why a model reached a conclusion. Explainable AI techniques such as Grad-CAM make it possible to visualize which regions of an X-ray influenced the model's output, supporting trust and clinical review rather than treating the model as a black box.
