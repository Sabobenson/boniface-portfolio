Office Network Design with VLAN, DHCP & Internet Access

Cisco Packet Tracer Academic Project

Overview

This project is a design and simulation of an office network implementing VLANs, DHCP, routing and Internet connectivity. It reflects a typical small-to-medium office environment where multiple departments need isolated, well-managed network segments that still share a common path to the Internet.

Design Approach

  • Segmented the office into separate VLANs by department to isolate broadcast traffic and improve security.
  • Configured a DHCP service to automatically assign IP addresses to end devices within each VLAN.
  • Implemented inter-VLAN routing so devices in different departments could communicate where required.
  • Planned an IP addressing scheme to avoid overlap and allow for future growth.
  • Connected the internal network to an Internet-facing router to provide external connectivity.

Outcome

The simulated network demonstrates a working, segmented office topology where devices receive addresses automatically, departmental traffic stays logically separated, and all segments retain reliable access to internal resources and the Internet.
